# Color Lab – Exploring Color Theory & Psychology

Media pembelajaran interaktif (3D + AR + GenAI) untuk mengeksplorasi roda warna, warna hangat–dingin, harmoni, kontras, dan psikologi warna.

- **Slide 3D interaktif** (Three.js): roda warna RYB 3D, poster, dan kemasan yang warnanya berubah langsung.
- **AR Scan kartu** (MindAR): arahkan kamera HP ke kartu Color Lab (folder `cards/`).
- **AI Lab**: GenAI (Gemini via Google Apps Script) membuat variasi palet dan skenario latihan.
